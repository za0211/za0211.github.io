# セルフ姿勢チェック（AI姿勢分析アプリ）

正面・側面の全身写真から、肩や骨盤の傾き・頭の位置・猫背や反り腰の傾向などをAIで分析するWebアプリです。
整体・骨盤矯正・姿勢改善のサロン向けに作りました。現在は **Cafuné body&face care** のデザインで公開しています。

- 公開URL：https://za0211.github.io/posture/
- 置き場所：GitHub リポジトリ `za0211/za0211.github.io` の `posture/` フォルダ
- サーバー不要：HTML / CSS / JavaScript だけで動きます。写真は端末の外へ送信されず、分析はブラウザの中で行います。

---

## 1. 別のプロジェクト・別のお店で使うとき（引き継ぎ手順）

`posture/` フォルダをまるごとコピーすれば、そのまま動きます（`tests/` はなくても動作します）。

1. **`config.js` を書き換える** … お店の名前、予約ページのURL、履歴の保存名、判定の基準値など
2. **`index.html` の文章を書き換える** … ページタイトル、見出し、紹介文、予約への誘導文（`Cafuné` `カフネ` で検索すると該当箇所が見つかります）
3. **`style.css` の色・フォントを変える** … 先頭の `:root { ... }` の色を変えるだけで全体の色が変わります（`--brand` がメイン色、`--brand-deep` がボタン色）。見出しのフォントは `--serif`、読み込みは `index.html` の Google Fonts 行です
4. **公開する** … 下の「3. 公開のしかた」を参照
5. **動作確認** … 下の「4. 動作確認テスト」を参照

> `config.js` の `historyKey` をお店ごとに別の名前にしておくと、同じ端末で別のお店のページを開いても履歴が混ざりません。

## 2. ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構成と文章（ヘッダー、紹介文、撮影ガイド、写真の枠、結果、履歴） |
| `style.css` | デザイン。先頭の `:root` に色などの設定がまとまっています。スマホ・ダークモード・印刷用の指定も含みます |
| `config.js` | **お店ごとに変える設定**（ブランド名、予約URL、結果画像のタイトル、履歴の保存名、判定基準、スコアの重み） |
| `app.js` | 本体。AIの読み込み → 体のポイント検出 → 角度の計算 → 判定 → 描画・結果表示・履歴保存 |
| `tests/` | 動作確認用の自動テスト（公開には不要） |

### app.js の中身（上から順に）
- **Model**：MediaPipe Pose Landmarker の読み込み（GPU が使えなければ CPU に切り替え）
- **Scoring helpers**：基準値から「良好／軽度／要注意」と 0〜100 点を出す
- **Geometry / Front / Side**：正面・側面それぞれの計算（`analyzeFront` / `analyzeSide`）と、側面の姿勢タイプの推定（`postureType`）
- **Advice**：気になる項目ごとのセルフケア文（`adviceFor`）。文章の変更はここで行います
- **Drawing**：写真の上に骨格・基準線・重心線・数値を描く
- **View controller**：写真の読み込み、ポイントのドラッグ修正、正面／背面の切り替え
- **Overall result / History / Report image**：総合スコア、前回比較、ブラウザ内の履歴、結果画像のダウンロード

## 5. 分析の仕組み

[MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（Google）で体の33か所のポイントを検出し、そのうち耳・肩・股関節・膝・足首の位置から角度を計算しています。

### 正面（背面）の写真
| 項目 | 計算方法 | 基準（良好／軽度） |
|---|---|---|
| 肩の高さ（左右差） | 左右の肩を結ぶ線の傾き | 1.5° / 3° |
| 骨盤の傾き（左右差） | 左右の股関節を結ぶ線の傾き | 1.5° / 3° |
| 頭の傾き | 左右の耳を結ぶ線の傾き | 2° / 4° |
| 上半身の左右シフト | 肩の中心と両足首の中心の横ずれ（身長比） | 1.5% / 3% |
| 骨盤の左右シフト | 骨盤の中心と両足首の中心の横ずれ（身長比） | 1.5% / 3% |
| 脚のライン（O脚・X脚） | 股関節と足首を結ぶ線から膝がどれだけ外／内にずれるか（脚の長さ比） | 2.5% / 5% |

左右は「写真の中の位置」と「正面／背面」の選択から決めています（正面なら写真の左側＝本人の右側）。

### 側面の写真
| 項目 | 計算方法 | 基準（良好／軽度） |
|---|---|---|
| 頭の位置（ストレートネック傾向） | 肩→耳の線が真上からどれだけ前に傾くか（+3°までは許容） | 7° / 15° |
| 上体の傾き（猫背・反り） | 股関節→肩の線の前後の傾き | 4° / 8° |
| 骨盤の前後位置 | 足首→股関節の線の前後の傾き（+1.5°を基準） | 3° / 6° |
| 膝の伸び具合 | 股関節と足首を結ぶ線から膝が前（曲がり）／後ろ（反り）にずれる量 | 4° / 9° |

体の向き（右向き／左向き）は鼻と耳の位置から自動で判定します。見えている側（左右のうち検出の確かさが高いほう）のポイントを使います。

### 総合スコアと姿勢タイプ
- 各項目を 0〜100 点にし、`config.js` の `weights` で重み付けした平均が総合スコアです
- 側面の結果の組み合わせから「スウェイバック傾向」「反り腰傾向」「猫背傾向」「フラットバック傾向」「ストレートネック傾向」などを推定します（`app.js` の `postureType`）

## 6. 注意点・制限

- **基準値は仮のものです**。一般的な目安をもとに決めた値で、医学的に検証されたものではありません。実際のお客様の写真で試し、施術の感覚に合わせて `config.js` で調整してください
- **骨盤の前傾・後傾そのものは測れません**。写真の関節位置からは骨盤の向きが分からないため、全体のバランスから「傾向」として推定しています
- 精度は写真の撮り方に大きく左右されます（カメラの傾き、服装、全身が写っているか）。画面の「撮影のポイント」に沿って撮るのが前提です
- AIがポイントを置き間違えた場合は「ポイント修正」で手で直せます
- 履歴は**その端末のブラウザ内だけ**に保存されます。端末を変えたり、ブラウザのデータを消したりすると見られなくなります。お店とお客様で共有もされません
- インターネット接続が必要です（AIの部品を jsdelivr と Google のサーバーから読み込むため）
- 画面にも「医学的な診断ではありません」と表示しています
